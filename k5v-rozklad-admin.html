Адмінка розкладу викладачів

Розклад ведеться за принципом Чисельник / Знаменник — окремо для непарного і парного тижня, без прив'язки до конкретних дат. TV-екран сам визначає, який зараз тиждень, і показує потрібний розклад.

Налаштування

Про OneDrive: браузер TV-екрана не може напряму «зайти» у ваше хмарне сховище без або (а) синхронізованої локальної папки, або (б) прямого посилання на файл.
• Найпростіше і найнадійніше: встановіть OneDrive на обидва пристрої (адмінку й TV), покладіть schedule.json у синхронізовану папку, а на TV-пристрої роздавайте файли простим локальним сервером (не відкривайте як file://) — зміни підтягнуться самі протягом хвилини після синхронізації OneDrive.
• Альтернатива: зробіть файл у OneDrive «доступним за посиланням» і вставте пряме посилання на завантаження у поле «URL розкладу» вище — тоді TV буде намагатись завантажити саме звідти. Це залежить від налаштувань доступу OneDrive і може не спрацювати через обмеження CORS — перевірте на своєму пристрої.

Публікація на GitHub (щоб не заходити на github.com вручну)

Одноразово налаштуйте нижче, і кнопка «Опублікувати на GitHub» буде напряму комітити schedule.json у ваш репозиторій через GitHub API. Vercel підхопить пуш і передеплоїть сайт сам (якщо у вас увімкнена автозбірка з гілки) — TV оновиться протягом ~1 хв (він і так перевіряє файл раз на хвилину).
Токен зберігається лише у цьому браузері (в localStorage) — він не потрапляє в експортований JSON і нікуди не надсилається, крім самого GitHub API.
Створіть токен на github.com/settings/tokens (Fine-grained, scope тільки для цього репозиторію, права Contents: Read and write) — не використовуйте токен із ширшими правами, ніж потрібно.
